# 감염관리 PPE 선택 게임 - 안정화 수정본

수정 반영:
- game.js 전체 재작성으로 실행 오류 제거
- 체력 3개 정상 동작: 오답 1회마다 하트 1개 감소, 0개에서 종료
- 속도 100 유지
- 클린이/버블이 말풍선 고급화
- 말풍선 글씨 크기 17px 유지
- 캐시 방지 쿼리 v4 적용


## 데미지/말풍선 수정
- 말풍선 아래 삼각형 꼬리 제거
- 오답 시 버블이가 정답 보호구를 말풍선으로 안내
- 오답 시 화면에 빨간 플래시 효과 적용
- 오답 시 하트가 흔들리고 빛나는 데미지 효과 적용


## 시작화면 말풍선 추가
- 시작화면에서 클린이/버블이가 랜덤 말풍선 표시
- 클린이/버블이 말풍선은 약 2.4초마다 변경
- 게임 내 말풍선은 큰 삼각형 대신 작은 다이아몬드 노치 형태로 개선


## 오답 말풍선 줄바꿈 수정
- 오답 시 버블이 말풍선을 `앗 틀렸어!` / `정답: OOO` 두 줄로 표시
- 말풍선 줄바꿈 처리 함수가 `\n`을 우선 반영하도록 수정
- 버블이 랜덤 멘트에 `사랑의 병원 화이팅!` 추가


## BGM 추가
- 시작/메인 화면: bgm_center.mp3
- 환자 내려오는 게임 화면: bgm_battle.mp3
- 모바일 자동재생 제한 때문에 첫 터치/클릭 후 음악 재생
- 우측 상단 🔊/🔇 버튼으로 음소거 가능


## Firebase TOP100 랭킹 추가
- 게임 종료 시 scores 컬렉션에 점수 저장
- 저장 필드: department, name, score, createdAt, playTime, userAgent
- TOP 100 랭킹 표시
- 100위 밖 점수도 서버에 저장
- 랭킹 새로고침 버튼 추가
- 개인정보 안내문 추가
